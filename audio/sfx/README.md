# SFX — intentionally empty

Nectar's sound effects are not files. They are synthesised in code at runtime
by the `Sound` module in `index.html` (search for `── AUDIO ──`).

- Hear them all: open the game with `?soundtest=1`.
- Change one: edit its function in the `Sound` module.
- Full explanation: `../README.md`.

This folder exists so the answer to "where are the sound effects?" is here
rather than nowhere. If a recorded one-shot ever gets layered under an effect,
it goes in this folder.
